# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

## [0.1.0] - 2026-02-25

### Added
- `/presearch` skill to generate and iterate `research.md`
- `/deepplan` skill to generate and iterate `plan.md`
- Human++ marker conventions (`!!`, `??`, `>>`) for annotation loops
- Guard and lint scripts for phase gating and artifact quality checks
- Templates for `research.md` and `plan.md`
