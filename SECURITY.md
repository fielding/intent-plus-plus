# Security Policy

## Reporting a vulnerability

If you believe you have found a security vulnerability, please do not open a public GitHub issue.

Instead, send details privately to the maintainer via GitHub profile contact or another agreed channel.

## Scope

This project is primarily a workflow plugin (skills, scripts, templates).
Security concerns may include:

- unexpected command execution
- unsafe defaults in scripts or hooks
- path traversal or destructive operations

## Response

We will acknowledge reports and prioritize fixes based on impact and exploitability.
